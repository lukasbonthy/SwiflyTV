# Swifly seasonal artwork

## Interface details

`blossom-branch.svg`, `web-corner.svg`, `spider.svg`, `winter-lights.svg`, `fern-corner.svg`, `orbit-lines.svg` and `film-frame.svg` are original, static vector illustrations drawn for Swifly's theme details. CSS controls their movement and visibility so motion and device preferences stay authoritative. Their local SVG content contains no script or external asset references.

## Scene backgrounds

Original project artwork generated using the built-in imagegen tool. The supplied images were encoded to WebP without changing their composition. Runtime uses these local files, with CSS lighting and a dark canvas when an image cannot load.
