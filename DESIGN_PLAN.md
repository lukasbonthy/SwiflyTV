# SwiflyTV clean liquid glass design

Use the ShuttleTV reference for a compact centered floating header, a black background, restrained type and clear artwork. Keep the existing SwiflyTV routes and server playback behavior.

The catalog uses portrait posters with captions underneath. Playback links, save buttons and details links are separate interactive elements. The hero uses a complete title and actual metadata. Navigation contains Home, Movies, Series, Discover and List; other destinations remain in the profile menu.

Glass surfaces use a shared local renderer, with a frosted fallback and reduced transparency support. Refraction is activated near the viewport and released offscreen. Existing player controls retain their own implementation.

Continue Watching uses an isolated landscape card component shared by the homepage and history page. Show progress only from actual elapsed time and duration. Use consistent row headings, plain View all links and quiet glass reflections.

Validate JavaScript syntax, CSS parsing, generated pages and browser interactions before publishing. Record the limits of mocked checks; live third party playback and a real browser render require separate verification.
