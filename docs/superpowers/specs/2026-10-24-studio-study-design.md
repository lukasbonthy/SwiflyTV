# Swifly Studio and Swifly Study

## Intent and constraints
Implement every feature in the attached owner brief, plus merge the working lofistudy.to experience into a redesigned native /study page. Preserve all existing SwiflyTV features and the complete AI form. Work in feat/studio-study-expansion from main8d3cf95. Deliver an unmerged PR; the owner brief explicitly prohibits production merge/deploy without further authorization.

## Chosen architecture
Extend the existing Express + vanilla browser JS app, its Studio dialog, pageShell, actual homepage rows, liquid renderer, Aurora and player. Do not iframe another app, replace the app, add a framework, or invent data. A shared version2 validated flat settings schema retains every current v1 key; additive modules own persistence, Studio UI, page effects and player integration. Flat fields keep current data attributes and existing tests compatible while separate records isolate appearance, named looks and device-local overrides.

The alternatives were a second embedded app (incoherent navigation/auth/performance) and a wholesale SPA rewrite (unnecessary regressions). Native integration is the implementation choice because the existing systems already provide the required UI, auth, player and Socket.IO.

## State and portability
Use version2 {values,looks} records. Guest retains swiflytv.appearance; real profile records use a validated account/profile namespace derived from existing session/activeProfile context. Legacy global/v1 appearance migrates safely into first use, without clearing other storage. Device preset overrides live in swiflytv.studio.device. Profile changes cancel an open draft and apply the newly selected owner; never write to the old owner accidentally. Cross-device theme sync is explicitly unavailable; portable file/paste sharing works.

Open clones the saved record, including named-look changes. Save commits; Cancel/Escape/controller B/programmatic dialog.close restore all changes. Defaults and subsection reset only affect the draft. Handle unavailable/quota storage with an error, not false success. Named look add/duplicate/rename/delete are staged in the same transaction. Export only validated portable settings and name/description/schemaVersion. Import max32KiB, strict keys, enums, ranges, no HTML/CSS/remote assets, future versions rejected; show pending summary before Preview import, then Save/Cancel.
